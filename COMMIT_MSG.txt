首页改为极简入口，并补一个采集交互过程的示例

网站是自用和给朋友用，不需要宣传性质，所以首页去掉了 hero、
三步走和功能卡片，只留下：一句话说明、登录/注册、以及一小段
"能收的不只是表格"。

和问卷工具最大的差别是能跳出表格：交互过程、反应时间、对错次数、
是否看过提示这类细节都能收。这个不该只写在文档里，所以加了
examples/反应测试.html —— 六轮反应力小游戏，把逐轮反应时间、
逐轮结果、抢跑次数、查看规则次数、总用时一起提交。

顺带修掉一个隐蔽的 bug：
`var status = document.getElementById('status')` 里的 status
撞上 window.status（浏览器内置的字符串属性），元素被强行转成字符串，
之后所有赋值静默失效 —— 成绩其实提交成功了，但界面上不显示任何提示。
同一个坑之前在 demo 里踩过一次，这次把它做成静态检查加进了
tests/check_examples.py，并补了一组反向验证（注入 bug 能抓到、
注释里的示例代码不会误报）。

其他：
- tests/check_examples.py 用 node --check 校验示例页的内联 JS 语法
- README 补充了"收过程而不是收表格"的说明和三个示例的用途
