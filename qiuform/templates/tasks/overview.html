{{ icon('image', 15, 'summary-ico') }}还能一起收文件（图片）

同一个地址也收文件：用 multipart/form-data 提交，文件会存到服务器上，数据里只留一个路径 —— 所以数据页和看板可以直接用 <img src> 把图片显示出来。文件字段名随便取，服务器会把它写成 attachment 字段。

请把页面里的数据以 POST 方式提交到 {{ urls.api }}，文件和表单一起用 multipart/form-data 上传。强调：不要将文件编码为 Base64 形式。

那句「不要 Base64」很重要：否则大模型常把图片转成一长串字符串塞进 JSON，体积膨胀三分之一还可能超限。

提交后数据长这样：

{
  "category": "橡皮",
  "attachment": "/files/{{ task.apiid }}/a1b2c3d4e5.jpg"
}
  • 单个文件不超过 {{ upload_max_mb }} MB，建议在页面里先压缩再上传
  • 一次可以传多个文件，这时 attachment 会变成数组
  • 支持 {{ upload_exts | length }} 种格式 {{ upload_exts | join(' · ') }}
看看命令行怎么测 
curl -X POST {{ urls.api }} \
  -H "Content-Type: application/json" \
  -d '{"name":"张三","score":85}'

# 把数据读回来
curl {{ urls.api_all }}

# 提交一个文件（-F 会自动用 multipart/form-data）
curl -X POST {{ urls.api }} -F "category=橡皮" -F "file=@photo.jpg"
